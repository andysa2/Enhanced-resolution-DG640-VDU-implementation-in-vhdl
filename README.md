# Expanded-resolution-DG640-VDU-implementation
Vhdl implementation of DG640 VDU and PCG, expanded to 80 x 25 resolution and colour.

This committ further extends the DG640 vhdl implementation, by taking the native resolution
from 64 x 16 to 80 x 25.

The DG640 and it's companion Programmable Character Generation (PCG), was created by David Griffiths
and published in a series of articles in ETI Electronics Today Magazine in the 1980's
